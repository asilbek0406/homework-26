# Apex Motors — Homework #26

Учебная копия сайта по макету `home.png` / `form.png` и требованиям Homework #26 Vibe Coding.

## Запуск

1. Откройте папку `apex-motors` в VS Code.
2. Запустите `index.html` через **Live Server**.
3. Axios подключается в `index.html` до `js/script.js`.

## Структура

- `index.html` — разметка страницы и модального окна.
- `css/style.css` — стекло, градиенты, свечения, hover и адаптивность.
- `js/script.js` — Axios, вкладки, циклы карточек, модалка и заказ.
- `data/data.json` — исходные данные из задания, без изменений.
- `images/` — локальные preview-изображения.

## Важно про изображения

В выданном ZIP были только `data.json`, `home.png` и `form.png`; 15 фотографий автомобилей в архиве отсутствуют. Поэтому для готового запуска добавлены локальные preview-изображения с теми же именами, которые указаны в `data.json`. Для финальной сдачи их можно заменить на выданные/скачанные фотографии, не меняя `data.json`.
